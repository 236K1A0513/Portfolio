# Chaitanya Portfolio

A responsive student portfolio built with HTML, CSS and JavaScript.

## How to use
1. Open `index.html` in a browser to preview it.
2. Replace the placeholder `#` links with your LinkedIn, GitHub and Resume URLs.
3. Replace `your-email@example.com` with your email address.
4. Add your actual certificates and work-sample links.
5. Upload the three files to a GitHub repository.
6. Enable GitHub Pages from the repository settings to publish the website.

## Files
- index.html — portfolio content
- style.css — design and responsive layout
- script.js — mobile navigation
